# 测试说明

## v1.1.0 的覆盖与边界

> [!WARNING]
> **上层修改器仅验证 TurboSmooth 与 OpenSubdiv 的常规已测路径。其他修改器、组合及特殊 GPU 显示模式未验证，不建议在它们下面使用 MQD。** 超出范围尝试可能出现崩溃、撤销错乱或数据损坏，请先备份、自行承担风险。

本轮使用中文 3ds Max 2024.2、独立测试对象及主线程原生接口。不同阶段的结果分开记录：

|---|---|---|

| 基础对象 / 上层细分接口 | 108/0 | TurboSmooth / OpenSubdiv 既定场景 |
| 会话退出与宿主上下文 | 292/0 | session3 既定路径；不涵盖后来发现的真实拖动焊接撤销故障 |

这些是不同阶段的分项证据，不能加总后当成“完整无故障证明”。session3 阶段曾出现真实移动+自动焊接后撤销错乱；后续修复采用两个原生撤销步骤，保留失败记录。用户随后反馈焊接试用、细分操作和中途选择修改器正常；又反馈 Tab 试用正常并提供 OpenSubdiv 截图。没有逐次记录的按键、GPU 模式和任意中途取消组合，不据此宣称全部通过。

脚本入口：`MQD_StackAdapterTest.ms`、`MQD_SessionLifecycleTest.ms`、`MQD_UI_SelfTest.ms`、`MQD_WarmLifecycleTest.ms`、`MQD_AutoWeldUndoTest.ms`、`MQD_SettingsTabTest.ms`。按各脚本的场景/夹具约束执行；原生事件与延迟回调需要分阶段等待，禁止拿用户生产模型充当测试夹具。

尚未全面验证：其他修改器、OpenSubdiv 特殊 GPU 路径、所有在途 Move/Border/整圈/Relax 中断组合、参考目标同点面数的几何改变、长期复杂场景、其他语言和其他 Max 主版本。手测反馈是范围内的验收，不是无限兼容承诺。

- 原有补面自检 **81 项 / 0 失败**。

这是现有机器的**升级安装与冷启动**验证，不冒充干净新机器的 MZP 拖入安装/卸载验收。测试中的两个早期探针误把按需加载函数当作启动即存在；随后通过实际宏入口与已加载模块核验，相关原始错误保留在本机收据中。

## 独立规则测试

`tests/native` 中三个 C++ 程序直接使用实际插件的规则头文件，覆盖 121 项候选状态/朝向/共面顶点判断、71 项遮挡深度数值判断和 138 项 Tab 按键状态判断。构建命令见 BUILD.md。

## Max 内自检

保存自己的模型并切到空场景，确认 MQD 未激活。在“脚本 → 运行脚本”打开 `tests/max/MQD_SelfTest.ms`。

自检分 19 个事件执行，创建测试对象并保留在空场景。它不重置或保存场景，不清空撤销，不改变视图方向。结果写在脚本同目录的 `MQD_自检结果_2026-09-16.txt`；日期文件名为沿用的测试标识，并非每次运行日期。

v4 的预期结果是 `checks=81 failures=0`。测试内容包含前后表面层、内部/边界点、三点共旧面、方向准备、预览过期、严格提交、准确点序与完整流程的撤销/重做。

历史首版基线桥接为 `0.17.6-max2024-v16-unified-stepbuild`，2026-09-16 自检为 81/0。v1.1.0 桥接为 `0.17.9-max2024-v16-settings-tab`，本轮历史候选阶段也重跑了同一组补面回归；正式文件以对应标签的 SHA256SUMS.txt 为准。

## 实际场景回归

使用模型副本，检查正常补面、背面点排除、折叠/薄层、点边面移动、边界延展、自动焊接、删除、撤销与重做。注意自动焊接需先撤焊接再撤移动两步，普通操作按原生历史撤销。确认预览和实际新面一致。

退出显示状态另行检查：进入前关闭顶点标记，进入 MQD，再分别右键退出和切换其他工具，确认恢复关闭。进入前本来开启时，当前设计恢复开启。该显示生命周期不是 81 项建面自检的全部覆盖范围。

首版安装器做了发布清单更新与静态验证，干净 Max 环境安装/卸载、其他语言和其他 Max 主版本未据此宣称通过。测试失败时保留结果，向 Issues 提供脱敏信息。
