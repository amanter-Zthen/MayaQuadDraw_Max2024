# 安装与使用

> [!WARNING]
> **修改器兼容性警告：请先阅读，再决定是否使用。**
>
> **目前仅验证 Editable Poly（可编辑多边形）基础对象，及其上方 TurboSmooth（涡轮平滑）或 OpenSubdiv 的已测常规路径。其他修改器、任意组合和特殊 GPU 显示模式尚未验证。** 不建议保留未测上层修改器时在基础层使用 MQD。
>
> 超出范围可能出现显示异常、撤销错乱、崩溃或模型数据损坏。风险已提前告知；如仍自行尝试，请先另存副本并自行承担使用风险（**后果自负**）。重要模型保留独立备份。

## 首次安装

目标为 Windows x64 上的 3ds Max 2024。请先保存需要保留的场景，从本仓库 Release 下载 `MayaQuadDraw_Max2024_v1.1.0.mzp`，拖入 Max 视口安装，再重启 Max。可用同名 `.sha256` 核对安装包。

文件安装到 Max 的当前用户目录，不写入 Max 主程序目录：

- 用户脚本目录：`MayaQuadDraw_Max2024/runtime`、`plugins`、`docs` 和 `logs`。
- 用户启动脚本目录：`MayaQuadDraw_Max2024_Startup.ms`。
- 用户宏目录：`MayaQuadDraw_Max2024.mcr`。

在热键编辑器中找到 `MQD Tools` 分类的 `MQD Quad Draw` 动作，手动分配快捷键；推荐 `Ctrl+Shift+Q`。工具不自动改写已有快捷键。

工作网格必须是一个 Editable Poly，参考表面为另一个对象。通过原生 PolyDraw 的 Pick/拾取指定参考表面，然后选择工作网格并启动工具。

## 参数窗口与退出

- 绘制启动时默认不弹出参数窗。**MQD 激活、焦点在绘制视口时按 Tab** 显示，再按 Tab 收起；长按只切换一次，拖动中不弹窗打断手势。
- 点进参数数值框后，Tab / Shift+Tab 保持字段导航。需要开关面板时先把焦点交回视口。
- 也可通过 `MQD Tools` 分类下的设置动作单独开关面板。窗口记住位置；关闭面板不等于退出绘制。
- 右键退出、切换工具或选择上层修改器后，MQD 的活动状态结束；退出后不接管 Tab，几何撤销也不重新开启绘制。
- **移动并自动焊接后需要两次撤销**：第一次撤焊接、第二次撤移动。普通未焊接拖动仍为一次；有效绘制会话内正常撤销后可以继续绘制。

## 升级

1. 保存模型副本，退出 Max。
2. 重新打开 Max，暂时不要启动 MQD，再运行新版 MZP。已加载的 DLX 不能在本次进程中安全替换，安装器会提示停止。
3. 安装器会把已有对应文件保存在插件目录的 `install_backups` 子目录，再更新文件。复制失败时尝试恢复原文件。
4. 安装完成后再次重启 Max，用空场景和模型副本验证。

卸载或恢复备份时同样先确认原生插件没有被加载。不要安装早期本地实验 MZP 覆盖本仓库 Release；部分旧包包含过时宏和旧桥接文件。

## 卸载

在“脚本 → 运行脚本”运行安装目录中的 `Uninstall_MayaQuadDraw_Max2024.ms`。它移除本插件的启动脚本和宏注册文件，保留运行文件供重启后手工处理。重启 Max 后，可按卸载提示删除对应 MQD 安装目录。此操作不删除模型和场景文件；若手动绑定过快捷键，可在热键编辑器中自行解除。

## 已知显示状态

如果工具已退出但对象仍显示顶点方块，请选中对象，在“显示 → 显示属性”关闭“顶点标记”。MQD 会恢复进入前的显示状态；如果进入前该开关已经开启，退出后也会开启。这是对象属性，可随场景保存，与多出顶点或模型损坏不是同一回事。

## 验证范围

v1.1.0 在首版基础上完成了细分基础层、会话退出、两步焊接撤销和 Tab 参数窗口的分项检查，用户已反馈本轮试用正常。详细检查范围见 `TESTING.md`。本机升级验证不等同于所有机器的干净安装、所有 Max 语言或所有修改器组合均已验证。安装前保存需要保留的工作，在副本中试用；发现问题请通过 Issues 提交版本、堆栈和最小复现步骤。
