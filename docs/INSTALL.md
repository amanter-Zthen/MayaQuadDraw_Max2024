# 安装与使用

## 首次安装

目标为 Windows x64 上的 3ds Max 2024。请先保存场景，从本仓库 Release 下载 `MayaQuadDraw_Max2024_v1.0.0.mzp`，拖入 Max 视口安装，再重启 Max。

文件安装到 Max 的当前用户目录，不写入 Max 主程序目录：

- 用户脚本目录：`MayaQuadDraw_Max2024/runtime`、`plugins`、`docs` 和 `logs`。
- 用户启动脚本目录：`MayaQuadDraw_Max2024_Startup.ms`。
- 用户宏目录：`MayaQuadDraw_Max2024.mcr`。

在热键编辑器中找到 `MQD Tools` 分类的 `MQD Quad Draw` 动作，手动分配快捷键；推荐 `Ctrl+Shift+Q`。工具不自动改写已有快捷键。

工作网格必须是一个 Editable Poly，参考表面为另一个对象。通过原生 PolyDraw 的 Pick/拾取指定参考表面，然后选择工作网格并启动工具。

## 升级

1. 保存模型副本，退出 Max。
2. 重新打开 Max，暂时不要启动 MQD，再运行新版 MZP。已加载的 DLX 不能在本次进程中安全替换，安装器会提示停止。
3. 安装器会把已有对应文件保存在插件目录的 `install_backups` 子目录，再更新文件。复制失败时尝试恢复原文件。
4. 安装完成后再次重启 Max，用空场景和模型副本验证。

卸载或恢复备份时同样先确认原生插件没有被加载。不要安装早期本地实验 MZP 覆盖本仓库 Release；部分旧包包含过时宏和旧桥接文件。

## 卸载

在“脚本 → 运行脚本”运行安装目录中的 `Uninstall_MayaQuadDraw_Max2024.ms`。它移除本插件的启动脚本和宏注册文件，保留运行文件供重启后手工处理。重启 Max 后，可按卸载提示删除对应 MQD 安装目录。此操作不删除模型和场景文件；若手动绑定过快捷键，可在热键编辑器中自行解除。

## 已知显示状态

如果工具已退出但对象仍显示顶点方块，请选中对象，在“显示 → 显示属性”关闭“顶点标记”。MQD 会恢复进入前的显示状态；如果进入前该开关已经开启，退出后也会开启。这是对象属性，可随场景保存，与多出顶点或模型损坏不是同一回事。

## 验证范围

首版运行时来自已通过 81 项 Max 内测试的基线。首版更新了安装文件清单和包装，并完成静态与归档一致性检查；新的安装器尚未在干净 Max 环境进行交互验收。安装前保存工作，发现问题请通过 Issues 提交版本与提示信息。
