MQD local candidate: session-scoped Tab settings panel
Date: 2026-10-15
Record type: historical local-trial evidence, retained with its original scope.
Follow-up: user reported the Tab trial works and approved v1.1.0 publication.
The implementation is included in v1.1.0. Pending/delivery statements below
describe the candidate stage; not every focus/gesture combination was observed.

Request
- Bare Tab, while MQD drawing is active, toggles the existing settings panel.
- Parameters retain their values and the existing remembered window position.
- Drawing remains the same session; opening settings does not reload MQD.
- Outside MQD, Max retains its normal Tab. In parameter fields, normal Tab and
  Shift+Tab remain available for navigating the fields.

Identity
- Runtime: 1.0.0-max2024-v20-tabpanel1
- Bridge: 0.17.9-max2024-v16-settings-tab
- Relax: 0.20.1-max2024-sdk-paint-deform-base-object, unchanged
- Includes the accepted weldundo1 two-step native Move / AutoWeld behavior.
- Geometry, welding, candidate face and subdivision algorithms are unchanged.

Implementation
- Reuses the existing input DLX and Windows thread-local WH_GETMESSAGE hook;
  hook is registered for the current Max viewport/UI thread during SessionBegin.
- It requires owned MQD command, active viewport and exact viewport input focus.
- Bare Tab is consumed before accelerator/focus traversal; other keys pass on.
- One toggle per press; repeat does not flicker. Rapid queued presses use parity.
- During a drag or native Hold/restore, Tab does not interrupt the gesture.
- The existing one-shot session timer performs the UI action after dispatch
  unwinds. Generation, focus, history/context and gesture state are rechecked.
- Coalesced context/history events take priority and discard the UI request.
- On success, originating viewport focus is restored within the same Max root
  window and owned session. Explicit field focus still permits ordinary Tab.
- Exit removes this hook and pending state. No persistent/global key binding,
  new service, Python dependency or alternate Undo engine is introduced.

Required interactive acceptance
1. Active drawing viewport: Tab opens, Tab closes; holding Tab does not flicker.
2. Drawing, geometry, Undo/Redo and current modifier remain unchanged.
3. Clicking a parameter field: Tab/Shift+Tab navigate fields normally.
4. Return focus to viewport: Tab toggles again. Other Max editors retain Tab.
5. Exit MQD or select an upper modifier: this shortcut is released.
6. Reenter MQD: Tab works without restarting/reloading the tool.
